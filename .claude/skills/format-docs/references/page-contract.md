# CSVM format-page contract

## Landing pages

Use this order where applicable: **At a glance**, **Contents**, **Conceptual model**, **Reference**, **Reader rules and edge cases**, then **Evidence & limits**. Retain accurate existing material; an existing heading may satisfy a role.

## Child pages

Begin with `Part of: [family](../family.md).` State the source and scope, link back to the landing page, and nest the child in the root index.

## Root index

Group families by reader intent. Keep `extraction.md` and `gotchas.md` visibly first. List each family once and nest its children.

## Editorial boundary

Structural work may move material, clarify prose, repair navigation, and remove exact duplication. It must not change a technical claim; corrections require stated evidence. State the present format fact, not the history of discovering or correcting it; retain a date only when it identifies evidence.
